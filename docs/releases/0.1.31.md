# ATM 0.1.31

Owner-approved patch release from main. It stops an expired task claim from
blocking every agent's `next --prompt` in an adopter repository.

- `next --prompt` no longer treats a committed task ledger whose claim lease has
  expired (`heartbeatAt + ttlSeconds` in the past) as the current active task.
  Previously such a claim stayed `state: "active"` forever, so every clone
  routed unrelated work into `ATM_NEXT_ACTIVE_TASK_DIVERGENCE_BLOCKED`.
  Active-task divergence now uses the canonical `isLiveActiveClaim` predicate
  (state plus lease TTL); a live claim still blocks divergent work.

Publish the annotated `v0.1.31` tag through `.github/workflows/release-npm.yml`.

tarballs, verifies public npm parity, and promotes the pair to `latest`; no npm
