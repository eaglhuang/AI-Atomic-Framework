# ATM 0.1.25

Owner-approved patch release from main, following the 0.1.24 process in #435.
Scopes the stdin pathspec `git add` preflight to the current repository, so a
process running in another repository no longer blocks identity checks (#437).
Also disables that preflight inside the CLI test sweep and normalizes four test
sources to LF (#434).

Publish the annotated `v0.1.25` tag through `.github/workflows/release-npm.yml`.
As in 0.1.24, that workflow bumps workspace/package versions from the tag before
building; source manifests retain the development train. The existing OIDC
Trusted Publishing pipeline seals immutable CLI/starter tarballs, verifies public
npm parity, and promotes the pair to `latest`; no npm login is required.

The previous public version is 0.1.24. This release makes no new paper result or
win claim. If promotion fails, preserve promotion receipts and reconcile only
dist-tags still pointing to the candidate, following `docs/NPM_RELEASE_PARITY.md`.
Do not republish changed bytes at the same version. Mark a defective release
known-bad before a maintainer rollback or a fresh patch release.
