# ATM release surface budget

## Scope

This report records the local, reproducible release-surface contract for
`TASK-PRF-0012`. The npm adopter artifact and the portable onefile artifact are
separate products and must not embed one another.

## Contracts

| Surface | Input contract | Excluded surface | Gate |
| --- | --- | --- | --- |
| npm CLI package | `packages/cli/dist/npm-runtime` | source, tests, fixtures, evidence, root-drop payload | `validate:adopter-artifact-manifest`, clean-install smoke |
| onefile release | root-drop runtime closure selected by `isOnefilePayloadPath` | `packages/cli/dist/npm-runtime`, duplicate workspace copies, host governance projections | `validate:onefile-budget`, `validate:onefile-release`, reproducibility |

The package script may invoke either the direct builder
`scripts/build-onefile-release.ts` or the sealed wrapper
`scripts/run-sealed-runner-build.ts onefile`; the wrapper's inner onefile lane
must dispatch the same canonical builder.
