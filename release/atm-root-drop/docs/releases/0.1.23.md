# ATM 0.1.23

Owner-approved patch release from main, following the 0.1.22 process in #395.
Includes the P1 taskflow recovery fix (#394), the pinned 0.1.22 clean-smoke
evidence (#397), explicit multi-file quickfix scope with `next --claim --files`
(#399), and governed fast-forward framework base upgrades (#400).

For downstream framework source checkouts, use `atm upgrade base-sync` with an
actor and full current/target commit SHAs to update the base through the governed
fast-forward route. Consult `atm upgrade --help` for its preconditions. This is
separate from upgrading an installed CLI package to version 0.1.23.

Publish the annotated `v0.1.23` tag through `.github/workflows/release-npm.yml`.
As in 0.1.22, that workflow bumps workspace/package versions from the tag before
building; source manifests retain the development train. The existing OIDC
Trusted Publishing pipeline seals immutable CLI/starter tarballs, verifies public
npm parity, and promotes the pair to `latest`; no npm login is required.

The previous public version is 0.1.22. This release makes no new paper result or
win claim. If promotion fails, preserve promotion receipts and reconcile only
dist-tags still pointing to the candidate, following `docs/NPM_RELEASE_PARITY.md`.
Do not republish changed bytes at the same version. Mark a defective release
known-bad before a maintainer rollback or a fresh patch release.
